# Chat-bot for HR department (MAX)

Асинхронный бот для мессенджера **MAX**, созданный по аналогии с Telegram-ботом на aiogram 3.  
Предоставляет сотрудникам быстрый доступ к информации по кадровым вопросам.

## Возможности

- **Главное меню** с кнопками-сообщениями по разделам
- **Подменю отпуска** с inline-кнопками (оплачиваемый / без оплаты)
- Информация по: отпускам, копиям документов, донорству, электронным ключам, увольнению

## Установка

1. Python 3.10+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получите токен бота у поддержки MAX (бот должен быть создан в панели управления MAX)
4. Укажите токен через переменную окружения `BOT_TOKEN`:
   ```powershell
   $env:BOT_TOKEN="ваш_токен"
   ```

## Запуск

```bash
python bot.py
```

Бот использует long polling.

## Стек

- [maxapi](https://pypi.org/project/maxapi/) — Python-обёртка для MAX Bot API
- asyncio — асинхронная обработка запросов
